## 1.9.16 — 2026-10-10

**Maintainer review round 7 (CHANGES_REQUESTED on head 51443138): two of the three blockers closed, each reproduced on our tree before fixing**

- **Blocker 1 (security) — the veto proxy let IP-literal targets through.** The absolute-form HTTP branch of `startVetoProxy` fed straight into `policyGet`, and `policyGet` only carried the veto on the request's `lookup` option. For an **IP literal** target Node never calls `lookup` (it connects to the address directly), so the veto was a no-op there. Reproduced with the production proxy against a controlled local origin: `http://127.0.0.1:<port>/secret` returned **200 and the origin received the request**. Note the other blocked literals only produced 502 because those addresses are *unreachable*, not because policy said no — the canary therefore asserts both **zero requests** and that the 502 body names the policy reason (`blocked-host`), so an unreachable target can never make the guard look green. Fix in two layers: `policyGet` now applies the URL/host policy before connecting (the single literal entry point for every caller), and the proxy's HTTP branch pre-checks with an attributable error, mirroring the CONNECT branch. `checkedLookup` stays on the request for the DNS/rebinding case; a positive-control test keeps the allowed-hostname path working so the pipe isn't welded shut.
- **Blocker 2 (macOS) — a path alias made legitimate paths look like escapes.** `safeRel`/`assertContained` canonicalized the probe side with `realpath` but, when the root did not exist yet, compared it against the **uncanonicalized** `path.resolve(root)`. On macOS `/var/…` and `/private/var/…` are two spellings of one directory, so a project path was rejected and the command exited 1 (the reporter saw `preview-page` refuse valid thumbnail/audio paths). Both sides now use the same `canonicalPath` rule — deepest existing ancestor's `realpath` plus the not-yet-created tail — and `assertContained` gained the same "root doesn't exist yet, so an ancestor probe is legitimate" tolerance `safeRel` already had (still withheld whenever the root exists, which is the shape that lets a project-internal link point at the project's parent). Fail-closed is preserved: an existing root whose `realpath` throws is still rejected. macOS itself isn't reachable from here, so the regression reproduces the *mechanism* with a junction alias and runs on every platform; a negative case pins that a genuine escape through a link inside the project is still refused.
- **Tests +6 → 291 in fifteen files:** four production-proxy canaries (loopback literal → zero requests and a policy-named 502; private / metadata / IPv6 / zero / dotless literals all policy-named; hostname resolving to loopback still vetoed at connect time by `checkedLookup`; allowed hostname still served) and two alias cases (the legitimate path is allowed; the genuine escape is not). Red-proofs: removing both vetoes turns the loopback canary red; removing only `policyGet`'s assertion keeps it green (the layering control); removing the `canonicalPath` root side turns the alias regression red. Every restore is byte-compared.
- **Blocker 3 is unchanged and still ours-to-explain:** exact-head execution evidence needs a base-repo administrator to approve the queued runs (the fork author gets 403, documented upthread); the mirror repository's dual-platform CI remains the substitute evidence.

## 1.9.14 — 2026-09-28

**Field handoff (Mavis, billing-arena project): the subtitle pill's `max-width` was unreachable dead code — subtitles wrapped at half the designed width, and the band gate couldn't see the collision** (A/B reproduced on our tree with the reporter's probe before fixing: 22 real narration sentences, 8 wrapped wrong; the fix yields 0 wraps)

The `max-width: 1400px` rule could never bind — subtitles wrapped at ≈22 chars instead of the designed ≈33, double-height pills reached 230px from the bottom and covered captions/disclaimers on two slides. `left:50% + translateX(-50%)` centering and `max-width` are mutually exclusive; the pill CSS now lives once in `tools.subPillCss()` (single source with `SUB_GEOMETRY`, which also gains `padYPx/radiusPx/bottomFrac/sub2Em` so no literal survives outside tools) **with `width:max-content`**, and capture injects it verbatim. Consequence worth stating: `subLineCap`'s pinned numbers (24/33/35) were the *designed* values all along — the implementation had never matched them until now.
- **P0 · the band gate was both too small and blind:** `check-slides` 5e hard-coded a 168px band (single line actually measures 170; a wrapped pill reaches 230 — a 62px collision zone never reported while two slides were really covered). The band now comes from `tools.subBandTop()` computed from the same geometry (single-line vs bilingual double-line tiers, reading each slide's `text2`), and a new heuristic warns on **flow-anchored bottoms** (`margin-top:auto` / flex-spacer shapes) that the absolute-only scan never saw — both point at `grab-frames` for the definitive check, because a still preview cannot show subtitles at all.
- **P1 · `.disclaimer` no longer bakes in `max-width:1240px`** (previously reported, unfixed): that cap was designed for one-line source attributions and trapped full-width multi-line disclaimer blocks (an explicit `width:100%` couldn't override it). Projects that want it narrower override it themselves. This changes the generated tokens.css body, so old projects' managed region turns stale until `--upgrade-css` — the designed propagation.
- **P2 · `--ids` partial matches no longer render silently less:** unknown ids in `--ids` are now named in a warning (with the effective id list printed) in both `capture` and `grab-frames`; the message also covers the PowerShell shape where a bare `03,05` is evaluated as a number array and loses its leading zeros. (The reporter's earlier "`--ids` only honours the last one" was **retracted** — quoting the argument fixes it; the real skill-side gap was this silence.)

## 1.7.0 — 2026-09-18

**Third review round: the CSS-propagation rewrite, stale-CSS blocking, and six silent-failure paths closed**

**CSS propagation is now a single managed region (`tokens`), and staleness blocks rendering.**
The skill writes its generated CSS into the project's `slides/tokens.css`. The old mechanism delimited only the three toolkit blocks (no-fx / charts / tables) and decided "up to date" by looking at *the one block it recognised*, which left four paths that reported `ok` while the project still rendered old rules: ① the same toolkit present **twice** (the later copy wins the cascade and was never examined); ② a stale copy **outside** the managed blocks (written by an older, append-style upgrade, or pasted by hand); ③ a **mangled closing delimiter** (the regex no longer recognises the block, so the old existence probe reported `ok`, and the upgrade emitted a *second* opening marker); ④ drift in the **generated body itself** (theme tokens, `--fs-*` scale, fx keyframes/utilities, `.fx-stagger`) was not managed at all. ## 1.0.0 — 2026-09-17

First public release.

**Pipeline**: kickoff alignment (language/style/subtitles/canvas/voice/asset boundaries) → research → script → TTS → measured timing → images → staged HTML entrance → frame-by-frame rendering → reverse ASR verification — 7 phases and 6 confirmation gates in total.

**Scripts (11, plain Node, no build step)**

| Script | Purpose |
|---|---|
| `init-project.mjs` | Generates the project skeleton (directory + tokens.css + slide templates + the script.json contract) |
| `plan-timings.mjs` | ffprobe-measures each TTS segment → duration, each level's entrance moment, each sentence's onset |
| `check-timing.mjs` | Silence detection measures each sentence's real onset, compares it with the estimate and can calibrate |
| `check-theme.mjs` | The WCAG contrast gate for every theme (body/secondary/subtitles/accent) |
| `check-slides.mjs` | Static checks before rendering (undefined variables / missing images / external resources / `data-stage` without animation / hard-coded colours) |
| `capture.mjs` | Final-state screenshots or frame-stepping capture, subtitles burned in by default |
| `build-video.mjs` | Encode → concatenate → align the audio track → mix BGM → mux → self-check + SRT |
| `asr.mjs` | ASR transcription compared against the script (direct REST calls); character-level timestamps can verify each sentence's onset |
| `prep-image.mjs` | Image checks and limited cropping (crop up to 20% of the area) |
| `fetch-official-images.mjs` | List and download candidate asset images from the official site |
| `tools.mjs` | Multi-anchor discovery of ffmpeg/ffprobe and Node packages |

**Design system**: 13 themes, 17 layouts, the image-frame primitive (`.img-frame`), 14 entrance/ambient animations, staged entrance and the stagger container.

**Language**: Mandarin Chinese / English / Cantonese — the character-count and speech-rate baselines, the subtitle line width and the ASR language check all switch with the language.

**Canvas**: 1920×1080 landscape and 1080×1920 vertical (the subtitle geometry adapts to the canvas ratio).

**Subtitles**: monolingual or bilingual, burned in, plus a separate `out/subs.srt`.

**Sound**: BGM underneath (optional, looped and faded in/out automatically), reverse ASR verification (voice language, consistency of numbers and proper nouns).

**Research**: `references/research.md` — four-tier source grading, the four hard rules (multi-source cross-checking / primary sources first / labelled scope and date / uncertain items stay out of the script), query design, handling contradictions across sources, the notes template, and the search tools available per environment (including mmx search's 10-result cap).

**Two toolchains**: the mcode sandbox uses platform connectors; other Agent environments use mmx-cli (for TTS) and this repo's `asr.mjs` (for ASR).

**Silent failures already fixed (all gated)**

- Entrance delays overridden by the `animation` shorthand → elements entered at 0 seconds (delays moved to variable slots)
- Undefined CSS variable + transparent text fill → the text becomes completely invisible (a static block in check-slides)
- Image load failure → a broken icon and no error (capture names it at runtime)
- Missing clauses → a subtitle-less video shipped silently (capture warns)
- Overlapping subtitle windows → two adjacent sentences visible at once, looking like "ghosting/typos" (the fade-out now reaches zero inside the window, plus a window self-check)
- Theme overrides ignored and only the first block taken for a selector of the same name (check-theme's merge semantics corrected)
