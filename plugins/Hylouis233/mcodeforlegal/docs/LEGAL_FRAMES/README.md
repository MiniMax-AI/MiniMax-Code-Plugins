# LEGAL_FRAMES — 法域基线文件

本目录承载 mcodeforlegal 插件集的**法域基线（legal frame）**：每个法域一个基线文件，汇总该法域的法源层级、核心法典结构、关键时效、效力规则等「定位性知识」，供 skill 运行时锚定检索路径。

> **所有基线文件均为模型知识整理，不构成法律意见。** 引用前必须经 statute-verify 核验（核验指引见各基线文件文末）。

## 法域解耦设计

1. **法域差异收敛到基线文件**：法源层级、时效、效力规则等法域特定知识只写在本目录的基线文件里，不进 skill 正文。
2. **frontmatter 锚定**：skill 通过 `metadata.legal_frame: cn-mainland` 声明默认法域；运行时加载对应基线文件。
3. **skill 不写死法域分支**：skill 内不出现「如果是中国大陆则……如果是香港则……」的分支逻辑；法域切换 = 切换基线文件 + 用户确认（法域五步识别，见 `docs/architecture.md`）。
4. **新增法域的最小步骤**：新增 `<frame>.md` 基线 → 在 `scripts/validate-skills.py` 的合法值清单中登记 → 需要时提供法域专用 connector。skill 本体无需改动。
