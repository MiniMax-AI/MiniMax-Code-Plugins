# 高频变动法规观察清单（currency watch）

## 使用规则

1. 引用本清单内任何法规前，先检查该条 **Last verified** 距今是否超过 **90 天**；
   超过必须经 statute-verify 重新核验后才能引用，不得沿用旧结论。
2. 各条的"复核建议"周期严于 90 天的，从其严。
3. 清单内法规的核验记录不受 verification-log.md 的 90 天复用宽限，
   按本条复核周期执行。
4. 发现新的高频变动领域法规（新出台、新修订、监管口径明显变化），
   建议补入本清单；补入时如实填写关注原因，不确定的细节标
   [模型知识—待核实]。

## 清单

### 1. 个人信息出境标准合同相关规定

- **法规名**：《个人信息出境标准合同办法》及标准合同文本、备案相关配套
- **关注原因**：个人信息出境合规路径（安全评估、标准合同、认证）的适用
  门槛与配套要求近年多次调整；2024 年出台的跨境流动促进规范对豁免情形
  做了重要放宽 [模型知识—待核实，具体条文以核验为准]，后续配套与窗口
  指导仍可能更新。
- **Last verified**: 2026-08-18
- **复核建议**：60 天；涉出境项目启动前必须即时核验，不受周期宽限。

### 2. 数据出境安全评估相关规定

- **法规名**：《数据出境安全评估办法》及申报指南、网信办相关答问与配套
- **关注原因**：申报门槛（重要数据、个人信息量级门槛）随跨境流动促进
  规范调整过 [模型知识—待核实]；申报流程与材料要求以网信办最新公布为准。
- **Last verified**: 2026-08-18

### 3. 公司法注册资本登记管理制度

- **法规名**：《国务院关于实施〈中华人民共和国公司法〉注册资本登记管理
  制度的规定》及市场监管总局配套登记规则
- **关注原因**：新《公司法》（2024-07-01 施行）确立有限责任公司注册资本
  五年实缴要求，存量公司过渡安排由该规定细化 [模型知识—待核实，过渡期
  细节以核验为准]；登记机关执行口径可能继续出台细化文件。
- **Last verified**: 2026-08-18
- **复核建议**：90 天；涉存量公司减资、出资期限调整事项前即时核验。
