# 劳动合同专项审查

## 目的

把一份劳动合同从「读一遍」变成「按法定框架 + 本方视角逐项过堂」：先定
审查视角（雇主/员工），再按必备条款、试用期、违约金限定、竞业限制四组
高频风险点逐项核对，结果按 🟢🟡🔴 分桶，产出可直接行动（改、谈、签、
停）的审查 memo。

本技能的核心纪律有三条：

1. **视角先行**：同一条款对雇主是管理工具、对员工是义务负担，不先定
   视角就无权下结论；视角由用户声明，不默认、不猜测；
2. **劳动法是强制性框架**：约定低于法定下限的无效，高于法定下限的
   合法——对劳动者更有利的条款只入 FYI（docs/scenes/labor-cn.md A8.1），不
   提示压低；
3. **商业数值比对立场，法定数值才是硬线**：工资数额、补偿倍数是否可
   接受，比对画像与本方预算立场；试用期上限、二倍工资等法定数值才
   是硬线，本技能不硬编码任何商业阈值。

本技能遵守 legal-core Shared guardrails（G1–G12）与docs/scenes/labor-cn.md；
冲突时以 legal-core 为准。

## 前置检查

1. 已按docs/scenes/labor-cn.md B1 完成：画像检查（无 [填空]）、路由确认（用户
   已认可劳动合同类型）。未经路由直接进来的，先补这两项。
2. blocks 红线初扫：文本或用户意图是否命中docs/scenes/labor-cn.md A8.1 blocks
   （维持不签合同状态、针对三期员工的解除安排、拖欠工资安排、规避
   社保缴纳）。命中即停止，按 blocks 纪律处理，不进入审查流程。
3. 文本完整可读；只有部分页、照片件或仅 offer 无正式合同的，在
   reviewer note 的「已读」行如实写明范围。
4. 用户角色已识别（律师/法务/HR/劳动者本人/其他），决定 G4 标头档位
   与 G5 后果门口径；画像未完成时按非律师档处理。
5. 利益冲突扫描（G11 + 场景 A6）：是否已就同一用工关系为对立方做过
   分析。发现迹象立即停止并提示冲突审查。

## 操作规程

### 第 0 步：Matter context（事项上下文）

- 查 `matters/_log.yaml` 是否已有相关事项；有的，把本次审查挂到该事项
  目录下（drafts/ 存放 memo），并在 notes.md 追加一条进展。
- 没有事项且可能伴随多轮谈判修改的，建议经 `matter-workspace` 建档
  （一句提示即可，不强制、不代为决定）。
- 一次性快审（用户明说「就看一下」）可不在事项下落，memo 仍按统一
  模板。

### 第 1 步：视角确认（决定风险视角）

二者必居其一，由用户明确声明：

- **雇主视角**：关注管理弹性与合规成本——合同期限结构、试用期设计、
  岗位职责表述、解除条款接口、违约金安排是否落在法定允许范围内、
  规章制度援引是否有效。
- **员工视角**：关注权益底线与陷阱——报酬与支付是否明确、试用期是否
  被拉长、违约金是否被滥设、竞业限制是否有补偿、解除条件是否被
  单边放宽。

用户答「双方都看看」的：提示 G11 边界，请其确认本方立场；坚持双视角
的，按员工视角从严（更保守），并在 memo 中说明口径选择。

### 第 2 步：必备条款核对

对照劳动合同法定必备条款逐项检查（劳动合同法第十七条 [模型知识—待核实，
引用前经 statute-verify 核验]，memo 中正式引用保持 [CITE:__]）：

1. **合同期限**：固定期限 / 无固定期限 / 以完成一定工作任务为期限，
   起止日期是否明确；连续订立固定期限合同的无固定期限触发风险
   [模型知识—待核实]；
2. **工作内容与工作地点**：岗位表述过宽（雇主视角下争议时可能被限缩
   解释）或过窄（员工视角下被调岗即构成违约风险）；工作地点是否
   具体到城市，「全国」「服从调配」类表述的有效性风险 [模型知识—
   待核实]；
3. **工作时间与休息休假**：标准工时 / 综合计算工时 / 不定时工时——
   后两种需经行政审批方可实行 [模型知识—待核实，引用前经
   statute-verify 核验]；未经批准直接约定特殊工时的，🟡 起步；
4. **劳动报酬**：数额、结构（基本工资/绩效/补贴）、支付日期是否明确；
   仅写「按公司薪酬制度执行」的，员工视角 🟡；低于当地最低工资
   标准的约定无效（地方标准数值 [需复核] 当地口径）；
5. **社会保险**：是否明确依法缴纳；「自愿放弃社保」「社保折现」条款
   无效风险高——员工视角 🔴 起步，雇主视角同样 🔴（补缴 + 滞纳
   金 + 工伤待遇全额自担风险）[模型知识—待核实]；用户意图以此
   规避缴纳义务的，命中 A8.1 blocks，停止；
6. **劳动保护、劳动条件和职业危害防护**：涉职业危害岗位是否如实
   告知危害因素与防护安排。

缺失项处理：必备条款缺失属 A8.1 work-but-ships，给整改建议与建议完成
时限，不阻断流程。

### 第 3 步：试用期合法性

试用期是劳动合同审查第一高频雷区，逐项核对（劳动合同法第十九条）：

1. **期限与合同期匹配**：合同期 3 个月以上不满 1 年的，试用期不得超过
   1 个月；1 年以上不满 3 年的，不得超过 2 个月；3 年以上固定期限及
   无固定期限合同，不得超过 6 个月（第十九条，memo 中正式引用保持
   [CITE:__]）。超期约定的，超出部分无效风险，🟡 起步；已按超期
   部分履行的，劳动者可主张赔偿 [模型知识—待核实，引用前经
   statute-verify 核验]；
2. **只能约定一次**：同一用人单位与同一劳动者只能约定一次试用期
   （第十九条）；续签、调岗后重新约定试用期的，无效风险——员工
   视角 🔴 起步；
3. **试用期包含在合同期限内**：仅签「试用期合同」的，试用期不成立，
   该期限视为劳动合同期限 [模型知识—待核实，引用前经 statute-verify
   核验]；
4. **试用期工资下限**：不得低于本单位相同岗位最低档工资或劳动合同
   约定工资的 80%，且不得低于当地最低工资标准 [模型知识—待核实，
   引用前经 statute-verify 核验]，memo 中正式引用保持 [CITE:__]；
5. **不得约定试用期的情形**：以完成一定工作任务为期限的合同、合同
   期不满 3 个月的（第十九条）。

试用期瑕疵属 work-but-ships：可经变更协议、补足工资差额补救，memo
逐项给整改建议与建议完成时限。

### 第 4 步：服务期与违约金限定

劳动法对劳动者承担的违约金采取法定封闭列举——**只有两类情形允许约定
由劳动者承担违约金** [模型知识—待核实，引用前经 statute-verify 核验]，
memo 中正式引用保持 [CITE:__]：

1. **专项培训服务期**：用人单位提供专项培训费用、进行专业技术培训的，
   可约定服务期；违反服务期约定的违约金不得超过用人单位提供的培训
   费用，且按未履行服务期比例分摊 [模型知识—待核实]。检查点：是否
   真实发生专项培训费用（普通入职培训、在岗带教不算）、费用凭证、
   服务期长度与费用规模是否匹配；
2. **竞业限制违约金**：见第 5 步。

除此之外约定劳动者违约金的——如「提前离职赔偿 X 万元」「未满合同期
赔偿招聘成本」——无效风险高：员工视角 🔴；雇主视角标 🟠 并提示该
条款大概率不可执行，依赖它做留人手段是误判。注意区分：由**用人单位**
承担的违约金或赔偿约定不受此限，合法有效，员工视角属有利条款入 FYI。

### 第 5 步：竞业限制审查

存在竞业限制条款的，三要件逐项核对 [模型知识—待核实，引用前经
statute-verify 核验]，memo 中正式引用保持 [CITE:__]：

1. **人员范围**：限于高级管理人员、高级技术人员和其他负有保密义务的
   人员；对普通岗位一刀切约定竞业限制的，有效性存疑，🟡 起步；
2. **期限**：解除或终止劳动合同后不得超过 2 年；超期部分无效风险；
3. **经济补偿**：竞业限制期内应按月给予经济补偿；未约定补偿的，
   司法实践主流口径支持劳动者按一定标准主张补偿，或主张条款对其
   无约束力 [模型知识—待核实；具体标准各地不一，[需复核] 当地
   口径]。

未约定补偿属 work-but-ships（可经补充协议补救）。雇主视角下额外检查：
补偿标准与劳动者违约金的匹配性——补偿过低、违约金畸高的组合在争议
中可能被调整 [模型知识—待核实]。

### 第 6 步：全量 blocks 复扫 + 按视角分桶 🟢🟡🔴

- 复扫docs/scenes/labor-cn.md A8.1 全量 blocks（本技能最常见命中点：「自愿
  放弃社保」条款、以合同安排掩盖不签书面合同的状态）；命中即停止，
  按 blocks 纪律处理。
- **🟢 可推进**：检查项全部落在法定框架与本方立场内，且涉及地方标准
  的数值已经当地口径核验。
- **🟡 需修订或需人判断**：条款偏离法定框架或本方立场但可补救；或
  地方标准数值未经核验（场景 B3：地方标准未核验最高 🟡）。
- **🔴 不得推进**：命中 blocks 红线或画像红线；或条款组合构成本方
  重大不利且不可经修改补救。
- 每个标记项按 G9 双轴标注（法律风险 🔴🟠🟡🟢 × 商业摩擦 阻碍/拖慢/
  费解/无感）；法律风险高但商业摩擦也高的，建议栏写替代方案方向，
  不只写「删」。

### 第 7 步：输出审查 memo

按下方模板输出。执行摘要只放机械性一行修改（如「第 X 条试用期『三个
月』改为『二个月』」）；凡是需要起草新语言的（重写薪酬结构条款、补
竞业限制补偿条款），建议栏写「**建议转法务/律师起草**」，不在 memo
里代拟。

### 第 8 步：后果门（按结论分级，对应 G5）

- 结论含 🔴：memo 首页明示「**不进入签署流程、不向对方作出任何
  承诺**」，按 G5 生成「带给律师的一页 brief」，非律师用户到此停止。
- 结论 🟢 且用户为非律师：签署前走 G5 动作闸门——显式确认知悉后果
  并获得明确指令（「继续」之外的含糊回应不算），同时生成律师 brief
  供快速复核。
- 结论 🟡：逐条给修改建议或「建议转起草」，改完可重新过一遍本技能。

### 第 9 步：收尾

- memo 中所有条文引用过 legal-core `citation-audit`（G10）；未核验的
  保持 [CITE:__] 占位，FAIL 状态不得外发。
- 过程产物按 matter-workspace 版本规则保存；已发给相对方的任何版本
  永不覆盖、永不删除。
- 向用户复述后果门结果与下一步选项，确认其理解——尤其非律师用户，
  复述是 G5 显式确认的前置动作。

## 常见误判与边界提示

1. **offer 与正式合同不一致**：offer 中的薪酬、职位承诺未写入正式合同
   的，争议时举证困难，员工视角 🟡；建议把关键承诺落进合同文本或
   以附件固定。
2. **名为「合作协议」「顾问协议」的用工文本**：符合劳动关系特征
   （人身从属性、经济从属性、组织从属性）的，存在被认定事实劳动
   关系的风险 [模型知识—待核实]，🟠 起步并提示按劳动关系框架
   评估。
3. **退休返聘、在校实习生**：不属标准劳动关系，法律适用不同
   [模型知识—待核实]；本技能结论不直接套用，提示另行评估。
4. **非全日制用工**：以小时计酬为主、日均工时受限的用工形式有专门
   规则（可口头约定、不得约定试用期等）[模型知识—待核实]；本
   技能清单按标准劳动关系设计，遇到非全日制文本提示差异点。
5. **涉外劳动合同**：外籍员工或境外履行的，触发场景 B5 升级与 G3
   法域识别，不在本技能继续推进。
6. **劳务派遣/外包文本**：审查对象是派遣协议或外包服务协议的，不
   适用本技能清单；提示三方结构与「假外包真派遣」风险 [模型知识—
   待核实]，建议咨询劳动法律师。

## 本技能不做什么

- 不代拟劳动合同条款或修改稿语言——需要起草的一律「建议转法务/律师
  起草」。
- 不设硬编码商业阈值（多少工资算合理、多长服务期算长），商业判断
  比对画像立场；法定数值才作硬线。
- 不对高于法定标准的有利条款提示压低——只入 FYI，记录不扩大。
- 不处理 blocks 事项的后续（不出规避方案，生成律师 brief 后停止）。
- 不覆盖工伤认定、社保稽核应对、群体性裁员方案——命中即按场景 B5
  升级。
- 不做「保证无劳动争议」的结论；任何审查都不能消除争议可能。
- 不做法律意见陈述：对非律师用户的全部输出受 G5 UPL 门控。
- 不直接手改画像：现场取得的立场经 `customize` 写回。

## 收尾与下一步

1. memo 交付后按第 8 步后果门分流：🔴 停止并转律师；🟡 修订后复审；
   🟢 走 G5 显式确认 + 律师 brief。
2. 全部引用过 `citation-audit`；需核验条文原文的经 `statute-verify`
   （核验通过后以 [已确认—日期] 标注填入）。
3. 审查中发现解除条款风险的，提示可另行加载 `termination-assessment`
   做专项评估。
4. 涉及竞业限制体系化安排的，提示一并审查配套保密协议与规章制度
   （后者路由 `employee-handbook-review`）。
5. 进入多轮谈判的，提示经 `matter-workspace` 建档，后续每轮修改挂
