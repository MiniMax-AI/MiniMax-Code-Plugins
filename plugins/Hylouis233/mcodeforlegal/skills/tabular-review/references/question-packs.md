# 场景问题包（question packs）

本文件是 `tabular-review` 的场景化问题库：把高频批量审查场景沉淀为
**复制即用的问题清单**，作为网格的 Q 列输入。定位与纪律：

- 问题包只定义「提取什么」，**不做法律定性**——格子的 status、Flags
  严重度与整改结论由调用方 skill 与律师按各自口径判断；
- 问题可增删：按画像红线、合同审查 checklist 与用户自定义问题合并
  后使用；超过 10 份文档仍先试点 3 份确认格式（见 SKILL.md 前置检查）；
- **本文件刻意不引用具体条文号**：涉及法定标准（试用期上限、竞业限制
  期限、违约金可约定情形等）一律以「法定上限 / 法定标准」表述，具体
  数值与条文由调用方经 `statute-verify` 核验后填入，未经核验保持
  [模型知识—待核实]；
- 「常见风险形态」是提取关注点的提示清单，帮助识别 🔴/🟡 候选格；
  命中形态不等于违法结论，提取不到一律填「未见」，不得编造。

## 场景一：劳动合同批量审查（10 问）

适用：同一用人单位的多份劳动合同、续签/变更协议按同一清单过一遍。
调用方通常为 labor-cn 插件，其三段式红线照旧适用于每个格子的判断。

- **Q1 合同期限**：本合同的期限类型与起止日期是什么？
  - 提取要点：固定期限 / 无固定期限 / 以完成一定工作任务为期限；起始日与届满日。
  - 常见风险形态：期限空白或仅写「长期」；起算日早于签署日（倒签迹象）；连续固定期限后续签方式的争议高发形态。
- **Q2 试用期**：是否约定试用期？期限、试用期工资与合同期限的匹配关系是什么？
  - 提取要点：试用期月数、试用期工资金额或比例、是否重复约定、是否仅签试用期合同。
  - 常见风险形态：试用期超过法定上限；试用期工资低于法定比例标准；对同一劳动者重复约定试用期。
- **Q3 工资结构**：工资总额与构成（基本工资、绩效、补贴等）如何约定？
  - 提取要点：工资金额与构成项、支付周期与支付日、加班费计算基数是否明确。
  - 常见风险形态：只写「按公司薪酬制度执行」无具体金额；拆分为极低基本工资加模糊绩效；大小写金额不一致。
- **Q4 社保**：社会保险与住房公积金的缴纳义务如何约定？
  - 提取要点：是否明确依法缴纳、缴纳基数与缴纳地、是否存在替代性安排。
  - 常见风险形态：约定「自愿放弃社保」或以现金补贴替代缴纳；缴纳地与实际用工地不一致且无说明——命中 labor-cn blocks 红线的典型形态。
- **Q5 竞业限制**：是否约定竞业限制？范围、期限与经济补偿各是什么？
  - 提取要点：适用人员范围、限制地域与业务范围、限制期限、补偿标准与支付方式、对应违约金。
  - 常见风险形态：只约定义务不约定补偿或补偿标准不明；期限超过法定上限；对全员无差别适用。
- **Q6 违约金**：约定了哪些违约金条款？触发条件与金额是什么？
  - 提取要点：违约金触发情形、金额或计算方式、所对应的义务条款。
  - 常见风险形态：在法定可约定情形之外设定违约金（如普通辞职即罚）；金额与可能损失明显失衡。
- **Q7 解除条款**：合同解除与终止的条件、程序如何约定？
  - 提取要点：约定解除情形、通知期限、经济补偿安排、交接义务。
  - 常见风险形态：约定法定情形之外的用人单位单方解除权；「公司可随时解除且不承担责任」类表述；解除程序完全缺失。
- **Q8 工时制度**：适用何种工时制度？加班安排与计酬规则是什么？
  - 提取要点：标准工时 / 综合计算工时 / 不定时工时；特殊工时是否注明审批依据；加班审批与计酬规则。
  - 常见风险形态：特殊工时制未见审批依据；约定「工资已包含全部加班费」且基数不明。
- **Q9 签字日期**：双方签字盖章与签署日期是否齐备？
  - 提取要点：签章主体是否双方齐备、签署日期、签字人身份与授权。
  - 常见风险形态：缺一方签章或日期空白；签署日期倒签；签字主体与实际用工主体不一致。
- **Q10 文本一致性**：合同正文与附件、offer、引用制度之间是否一致？
  - 提取要点：岗位、薪酬、工作地点在正文与附件/offer 间是否一致；引用的规章制度是否附文本或可查。
  - 常见风险形态：正文与 offer 薪酬不一致；引用未向劳动者公示的制度文本；多份文本条款互相冲突。

## 场景二：IP 归属批量审查（8 问）

适用：多份含知识产权归属条款的协议（委托/合作开发、技术服务、员工
知识产权协议等）横向审查。调用方通常为 ip-cn 插件。

- **Q1 职务成果约定**：职务成果 / 职务发明的权属如何约定？
  - 提取要点：职务成果的定义范围、权属归属、奖励与报酬安排。
  - 常见风险形态：完全未约定或定义模糊；把与职务无关的成果一并划归一方的过宽表述。
- **Q2 背景 IP 清单**：是否列明各方背景知识产权及其使用范围？
  - 提取要点：背景 IP 定义、清单附件、各方对背景 IP 的使用许可范围。
  - 常见风险形态：无清单导致边界不清；背景 IP 被默示转让或许可过宽的表述。
- **Q3 前景 IP 归属**：履约/合作中产生的前景知识产权归谁？
  - 提取要点：归属规则（归一方 / 共有 / 按贡献）、申请权与费用承担。
  - 常见风险形态：未约定归属；约定共有但未约定实施、许可与收益分配规则。
- **Q4 改进成果**：对既有成果的改进、衍生成果归谁？
  - 提取要点：改进与衍生成果的定义、归属、回授许可（grant-back）安排。
  - 常见风险形态：改进归属缺失；单方回授无对价且范围不清。
- **Q5 登记义务**：知识产权登记、申请与维持义务如何分配？
  - 提取要点：登记/申请义务人、时限、费用承担、配合义务。
  - 常见风险形态：义务主体不明；未约定怠于登记的后果。
- **Q6 转让限制**：是否限制一方转让、许可或质押相关知识产权？
  - 提取要点：转让/许可/质押限制、优先受让或优先许可安排。
  - 常见风险形态：无限制导致核心资产可自由外流；限制过宽影响正常经营处分。
- **Q7 保密衔接**：保密条款与 IP 归属条款是否衔接？
  - 提取要点：保密信息定义是否覆盖未公开成果、保密期限、公开发表/申请前的管控。
  - 常见风险形态：归属条款与保密条款互相矛盾；申请日前公开无任何管控安排。
- **Q8 违约救济**：违反归属或保密约定的救济是什么？
  - 提取要点：违约金或损害赔偿计算、行为保全类救济约定、成果返还与销毁义务。
  - 常见风险形态：无任何救济条款；救济与违约情形明显不匹配。

## 场景三：隐私政策批量审查（8 问）

适用：多个 App / 网站 / 产品线的隐私政策、个人信息保护政策按同一
清单过一遍。调用方自行定义 🔴 的负面条件（如命中画像合规红线）。

- **Q1 处理目的**：个人信息处理目的是否逐项列明并与业务功能对应？
  - 提取要点：目的清单、目的与功能/场景的对应关系。
  - 常见风险形态：以「等」「相关」兜底概括；目的与实际功能明显不对应。
- **Q2 收集清单**：收集的个人信息类型与字段是否逐项列明？
  - 提取要点：字段清单、收集方式（主动提供 / 自动收集）、第三方 SDK 收集披露。
  - 常见风险形态：清单笼统（「相关信息」）；未披露 SDK 或嵌入代码的收集行为。
- **Q3 敏感信息单独同意**：敏感个人信息是否单独告知并取得单独同意？
  - 提取要点：敏感信息类别、单独同意机制的描述、处理必要性说明。
  - 常见风险形态：敏感信息混入一揽子同意；未说明处理必要性与影响。
- **Q4 共享披露**：向第三方共享、转让、公开披露的约定是什么？
  - 提取要点：接收方类型或清单、共享目的、是否需要并取得单独同意。
  - 常见风险形态：概括授权共享给「合作伙伴」；无接收方清单或查询途径。
- **Q5 用户权利**：查阅、复制、更正、删除、撤回同意、注销等权利如何实现？
  - 提取要点：权利清单完整性、行使路径、响应时限。
  - 常见风险形态：权利缺项；只列权利不给行使路径；响应时限不明。
- **Q6 未成年人**：未成年人个人信息如何处理？
  - 提取要点：年龄门槛、监护人同意机制、是否有专门规则。
  - 常见风险形态：服务面向未成年人但无专门条款；无监护人同意安排。
- **Q7 保存期限**：个人信息的保存期限如何约定？
  - 提取要点：保存期限或确定期限的标准、到期后的处置（删除 / 匿名化）。
  - 常见风险形态：「永久保存」类表述；未写期限或确定标准。
- **Q8 跨境**：是否涉及个人信息出境？机制与接收方如何披露？
  - 提取要点：出境场景、合规机制描述、境外接收方信息与权利救济路径。
  - 常见风险形态：存在出境迹象但政策未披露；未说明境外接收方与救济方式。

## 场景四：供应商合同批量审查（8 问）

适用：采购/外包场景下多份供应商合同按同一清单过一遍，识别需要
谈判或整改的条款差异。

- **Q1 主体**：签约主体的名称、资质与签约代表是否明确？
  - 提取要点：主体全称、统一社会信用代码、签约代表授权、与实际履约方是否同一。
  - 常见风险形态：以简称或内设部门签约；签约主体与实际履约主体不一致。
- **Q2 标的**：合同标的（货物/服务的内容、规格、验收标准）是否明确？
  - 提取要点：标的描述、数量与质量规格、验收标准与验收流程。
  - 常见风险形态：标的一语带过；无验收标准或无验收期限。
- **Q3 价格**：价格、税费口径与价格调整机制如何约定？
  - 提取要点：单价/总价、是否含税、调价触发条件与程序。
  - 常见风险形态：价格空白「另行协商」；调价由一方单方决定。
- **Q4 账期**：付款条件、账期与发票要求是什么？
  - 提取要点：付款节点与账期天数、发票类型与开具时限、是否存在背靠背付款表述。
  - 常见风险形态：付款条件成就标准模糊；「收到第三方款项后再付」类背靠背条款。
- **Q5 违约**：违约责任如何约定？双方是否对等？
  - 提取要点：迟延履行与质量瑕疵的违约金或赔偿计算、责任上限、免责事由。
  - 常见风险形态：只约定一方的违约责任；责任上限严重不对等。
- **Q6 知识产权**：履约成果与既有知识产权的归属如何约定？
  - 提取要点：交付成果 IP 归属、供方既有 IP 的使用许可、知识产权瑕疵担保。
  - 常见风险形态：成果归属未约定；无侵权瑕疵担保与追责安排。
- **Q7 数据条款**：涉及数据处理时，数据权属、安全与保密如何约定？
  - 提取要点：是否接触或处理数据、数据权属、安全措施、泄露通知、返还与删除义务。
  - 常见风险形态：涉及个人信息处理但无数据条款；保密期限与范围缺失。
- **Q8 终止**：合同终止条件与终止后安排是什么？
  - 提取要点：任意解除权、违约解除情形、终止后的结算/交接/资料返还安排。
  - 常见风险形态：单方任意解除权不对等；终止后义务（结算、保密存续）缺失。
