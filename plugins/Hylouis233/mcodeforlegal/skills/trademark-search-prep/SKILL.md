# 商标申请准备

## 目的

把「想注册一个商标」变成「可注册性初筛 + 类别规划 + 检索策略 + 材料
清单」：先筛显著性与禁用情形，再按业务规划尼斯分类，再制定检索策略
交由人工执行，最后输出申请材料清单与时间线。

本技能的核心纪律有四条：

1. **模型不代替检索**：商标近似判断依赖官方数据库实时数据，本技能
   只输出检索策略与核对清单，实际检索由用户或代理机构在中国商标网
   等官方/商业系统人工执行并复核；本技能不声称已检索、不把训练
   记忆当作检索结果（G1 + 场景 A4 检索纪律）；
2. **不做「保证注册成功」的结论**：审查结论权在商标局，且存在盲期
   等不可控因素，本技能只给风险初筛与准备质量；
3. **blocks 不问动机细节先停**：命中抢注/囤积迹象的，先按场景
   A8.1 blocks 停止，不谈「怎么提高抢注成功率」；
4. **官方口径优先**：申请要求、费用、时限以商标局官网最新公布为准
   [模型知识—待核实]，memo 中一律注明核对路径。

本技能遵守 legal-core Shared guardrails（G1–G12）与docs/scenes/ip-cn.md；冲突时以 legal-core 为准。

## 前置检查

1. 已按docs/scenes/ip-cn.md B1 完成画像检查与路由确认。
2. blocks 红线初扫（场景 A8.1）：是否明知他人在先权利仍抢注的迹象
   ——用户主动提及特定竞品/他人在先品牌并要求「照着注册」「抢在
   他们前面」，或批量囤积意图明显的，停止并按 blocks 纪律处理。
3. 升级触发扫描（场景 B5）：涉外布局（马德里国际注册等）、诉讼中
   或已收异议/无效通知、高价值商标组合——命中即升级。
4. 标识信息可读：文字商标给准确文字，图形/组合商标请用户提供图样
   描述；只有模糊描述的，在 reviewer note「已读」行写明。

## 操作规程

### 第 0 步：Matter context（事项上下文）

- 查 `matters/_log.yaml`；品牌布局通常多轮多件，建议经
  `matter-workspace` 建档（一句提示即可，不强制）。

### 第 1 步：显著性初筛

对照法定框架初筛（memo 中正式引用保持 [CITE:__]，相关规则
[模型知识—待核实，引用前经 statute-verify 核验]）：

1. **通用名称/图形/型号**：仅有本商品或服务的通用名称、图形、型号
   的，缺乏显著性——如以「智能手机」注册于手机商品；
2. **描述性标志**：仅直接表示商品或服务的质量、主要原料、功能、
   用途、重量、数量及其他特点的——如「速效」之于药品；但经过
   使用取得显著特征并便于识别的，存在获准注册的例外 [模型知识—
   待核实]；
3. **其他缺乏显著特征的情形**：过于简单的线条、普通形式的广告
   用语等 [模型知识—待核实]；
4. **暗示性与任意性标志通常显著性较强**：暗示性（需要联想）与
   任意性（与商品无关的既有词汇）、臆造词显著性依序增强
   [模型知识—待核实]。

初筛命中缺乏显著性的，🟠 起步并给出方向（增加显著要素、改用
臆造词等），不写「肯定不能注册」。

### 第 2 步：禁用条款初筛（绝对理由）

对照禁用情形逐项排查 [模型知识—待核实，引用前经 statute-verify
核验]，memo 中正式引用保持 [CITE:__]：

- 与国家名称、国旗、国徽、军旗等相同或近似，以及与政府间国际
  组织、官方标志相关的禁用情形；
- 带有欺骗性、容易使公众对商品质量等特点或产地产生误认的；
- 有害于社会主义道德风尚或有其他不良影响的；
- 县级以上行政区划地名或公众知晓的外国地名的限制（有例外）
  [模型知识—待核实]；
- 与他人在先权利冲突的相对理由（在先注册商标、驰名商标保护、
  代理人代表人抢注、在先使用并有一定影响的商标）——**相对理由
  的最终判断依赖人工检索**，见第 3 步。

命中绝对理由禁用情形的，🔴 不得推进该标志的申请。

### 第 3 步：尼斯分类选择（核心类 + 防御类）

- 商标注册按商品和服务国际分类（尼斯分类）分 45 个类别 [模型知识—
  待核实]；具体类号与类似群划分以商标局现行分类表为准 [需复核]；
- **核心类**：覆盖现有主营商品/服务的类别——由用户列明业务，对照
  分类表定位，本技能给方法不给「必然正确」的类号断言；
- **防御类**：关联业务、易被攀附的类别，结合画像中的品牌规划与
  预算立场选择；防御注册的维持成本（不使用撤销风险 [模型知识—
  待核实，引用前经 statute-verify 核验]）一并提示；
- 类别选择是商业决策：本技能呈现选项与代价，由用户（必要时连同
  代理机构）拍板，不硬编码「必注册类别」。

### 第 4 步：近似检索指引（人工执行）

输出检索策略与核对清单，由用户或代理机构人工执行：

1. **检索渠道**：中国商标网（商标局官方查询系统）为基础渠道
   [需复核] 官网入口；商业检索工具可作辅助；
2. **检索要素**：相同及近似的文字、读音、含义、图形构图；跨类似
   群与跨类别的关联检索；
3. **盲期提示**：申请数据录入存在时间差，检索无法覆盖最新申请
   [模型知识—待核实]——这是「检索干净」不等于「注册无忧」的
   原因之一；
4. **复核要求**：检索结果由人工作出近似判断；本技能可协助整理
   检索结果清单（用户粘贴结果 [用户提供]），但不代替检索动作
   本身；
5. **结论口径**：未经人工检索复核的，memo 结论最高 🟡（场景 B3）。

### 第 5 步：申请主体与材料清单

- **主体**：公司名义或个人名义申请的要求差异（个人申请的主体
  资格限制 [模型知识—待核实]）；以画像登记的申请主体为准；
- **材料清单**（以商标局官网最新要求为准 [模型知识—待核实]）：
  申请书、商标图样（清晰度与尺寸规范）、主体资格证明文件、
  委托代理的委托书；优先权主张的（如有）相关证明；
- **代理选择**：自行办理与委托备案代理机构的利弊提示；涉复杂
  在先权利冲突的建议委托专业机构。

### 第 6 步：时间线与费用构成

- **时间线**（各阶段时限 [模型知识—待核实，引用前经
  statute-verify 核验]）：提交申请 → 形式审查 → 实质审查 →
  初步审定公告（异议期）→ 注册公告；整体周期以官方实践为准
  [需复核]；
- **费用构成**：官方规费（按类别计）+ 代理服务费（如委托）
  [模型知识—待核实]；具体金额以商标局官网与代理机构报价为准
  [需复核]——memo 不写死金额；
- **期限管理**：异议期、驳回复审期等法定期限提示经
  `matter-workspace` 记入事项节点。

### 第 7 步：输出准备 memo

按下方模板输出。申请文书填写定稿属用户/代理机构工作，本技能给
要点与核对清单。

### 第 8 步：后果门（对应 G5）

- 用户为非律师：提交申请前走 G5 动作闸门——显式确认知悉「申请
  不保证核准、费用不因驳回退还」等后果并获得明确指令，生成
  「带给律师的一页 brief」（标志描述、类别规划、检索缺口、时间
  敏感性）。
- 命中 blocks 的：停止，brief 说明命中点，不推进。

### 第 9 步：收尾

- 引用过 `citation-audit`；未核验保持 [CITE:__]，FAIL 不得外发。
- 关键期限记入事项节点；向用户复述检索缺口与下一步，确认其理解。

## 输出模板

```markdown
【保密标头：按 G4 二选一】

# 商标申请准备 memo：<标志名称>

## Reviewer note
- 来源：<标志信息来源 [用户提供]；画像品牌规划 [已确认—日期]>
- 已读：<材料范围>
- 标记：结论 🔴 不得推进 / 🟡 需补正或需人判断 / 🟢 可推进；
  单项 = 法律风险轴（🔴🟠🟡🟢）× 商业摩擦轴（阻碍/拖慢/费解/无感）
- 时效：<官方要求核查日期；未核验写"未核验"；检索执行情况另注>
- 使用前注意：<去向限制；非律师注明"本 memo 不是法律意见"；
  声明"近似检索未由人工复核时结论为初步意见">
```

（正文：显著性初筛表 → 禁用条款排查表 → 类别规划（核心类/防御类
及理由）→ 检索策略与核对清单 → 材料清单 → 时间线与费用构成 →
[需复核] 清单 → 下一步）

## 本技能不做什么

- **不做「保证注册成功」的结论**——审查权在商标局，盲期与主观
  判断均不可控。
- 不代替人工检索，不声称已检索官方数据库。
- 不提供抢注、囤积策略——命中 blocks 即停止。
- 不写死官方费用金额与审查周期——以官网最新公布为准 [需复核]。
- 不处理商标异议、无效宣告、驳回复审的实体对抗——命中即按场景
  B5 升级。
- 不代填申请书定稿——给要点与核对清单。
- 不做法律意见陈述：对非律师用户的全部输出受 G5 UPL 门控。

## 收尾与下一步

1. memo 交付后按第 8 步后果门走 G5 显式确认 + 律师 brief。
2. 全部引用过 `citation-audit`；条文核验经 `statute-verify`。
3. 人工检索完成后，提示将检索结果 [用户提供] 回填 memo，更新
   结论等级（降级须声明理由——G9）。
4. 涉及委托开发/合作设计品牌标识的，提示路由 `ip-assignment-review`
   先固定权属再申请。
5. 申请后收到驳回、异议通知的，按场景 B5 升级，不再由本技能推进。
6. 类别规划与品牌布局结论建议经 `customize` 写回画像，供后续
   申请复用。
