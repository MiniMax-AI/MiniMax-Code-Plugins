# 公司章程审查

## 目的

把一份章程从「读一遍」变成「对照 2023 公司法逐项过堂」：先核法定必备
事项，再比对新法要点，再检查自治空间条款的合法性边界，把结果分成
🟢🟡🔴 三桶，产出一份可直接行动（改、提请修订、签、停）的审查 memo。

本技能的核心纪律有三条：

1. **结论依附立场**：同一条款（如同股不同权安排）对控股股东是工具、
   对中小股东是风险，不先定立场就无权下结论（docs/scenes/corporate-cn.md A6）；
2. **区分强制与自治**：章程审查的核心是分清「法律强制规定的」「法律
   允许章程另行规定的」「法律未禁止章程约定的」三圈，错把自治条款当
   无效、或把强制规定当可约定，都是实质错误；
3. **只审不拟**：指出冲突与缺口、给修订方向，不代拟章程条款——需要
   起草的一律「建议转法务/律师起草」。

本技能遵守 legal-core Shared guardrails（G1–G12）与docs/scenes/corporate-cn.md；
冲突时以 legal-core 为准。公司法第四十七条（五年实缴）为确定性高条号；
其余条号（必备事项、法定代表人、忠实勤勉义务、审计委员会选项等）正文
出现处一律标 [模型知识—待核实，引用前经 statute-verify 核验]，对外产物
中的正式引用一律 [CITE:__] 占位后核验（G10）。

## 前置检查

1. 已按docs/scenes/corporate-cn.md B1/B2 完成：画像检查（B9 关键项无 [填空]）、路由
   确认（用户已认可走章程审查路径）。
2. 立场已判定：本方为控股股东 / 中小股东 / 公司本身 / 拟任董监高 /
   拟入股的投资方；立场决定每项条款的风险视角。
3. 公司类型已确认：有限责任公司 / 股份有限公司——两类公司的章程规则
   差异重大，混用即错；外商投资、国有背景公司另有专门规则，命中即
   提示按场景 B5 升级评估。
4. 文本完整可读（含历次修正案）；只有现行有效版而事项涉及历史沿革的，
   在 reviewer note「已读」行如实写明。
5. 用户角色已识别，决定 G4 标头档位与 G5 后果门口径。

## 操作规程

### 第 1 步：Matter context 与去向检查

- 查 `matters/_log.yaml` 是否已有相关事项；有的挂到该事项目录下。
- 询问产物去向：仅内部修订用，还是要提交股东会或登记机关？提交登记
  机关的章程文本走 Quiet mode（docs/scenes/corporate-cn.md A2），memo 与文本分开。

### 第 2 步：法定必备事项核对

对照公司法关于章程应当载明事项的规定 [CITE:__] 逐项核对：

- 公司名称和住所；
- 公司经营范围；
- 公司注册资本；
- 股东的姓名或者名称、出资额、出资方式和出资日期；
- 公司的机构及其产生办法、职权、议事规则；
- 公司法定代表人的产生、变更办法；
- 股东会/股东会认为需要规定的其他事项。

缺项逐项列出，属 A8.1 work-but-ships：给补全建议与时限，不阻断审查。
出资日期栏重点核对与五年实缴规则的衔接（见第 3 步）。

### 第 3 步：2023 公司法要点比对

逐项比对新法要点（条号除第四十七条外均标 [模型知识—待核实，引用前经
statute-verify 核验]）：

1. **五年实缴**：有限责任公司全体股东认缴出资应自公司成立之日起五年
   内缴足（公司法第四十七条 [CITE:__]）。章程出资期限安排是否对接；
   存量公司过渡期调整安排涉国务院配套规定的，提示经
   `capital-contribution` 专项处理，过渡期细节标 [模型知识—待核实]
   并强制 `statute-verify`。
2. **法定代表人**：由代表公司执行公司事务的董事或者经理担任；章程
   是否明确产生与变更办法；辞任与补位机制是否衔接 [CITE:__]。
3. **董监高忠实勤勉义务**：章程是否照搬或细化忠实义务与勤勉义务的
   要求；关联交易报告与回避、商业机会、同业竞争限制的章程化程度
   [CITE:__]。
4. **治理结构选项**：是否采用审计委员会替代监事会的安排（董事会中
   设审计委员会行使监事会职权）[CITE:__]；小规模公司简化治理（一名
   董事、不设监事）的适用条件与章程表述 [模型知识—待核实]。
5. **股权转让规则**：对外转让的通知与优先购买权程序，章程是否有
   另行规定（新法允许章程另有规定）[模型知识—待核实，引用前经
   statute-verify 核验]。
6. **职权配置**：股东会、董事会职权是否在法定清单基础上经章程调整；
   章程新增职权的边界（不得剥夺法定职权的底线）[模型知识—待核实]。

每项比对结论：符合 🟢 / 与新法冲突或与制度脱节 🟡（A8.1 work-but-ships，
给修订建议与时限）/ 违反强制性规定 🔴。

### 第 4 步：自治空间条款合法性边界

对章程中的自治条款，按「法律允许另行规定 / 法律未禁止 / 触碰强制底线」
三圈分类（依据带来源标注，拿不准的标 [需复核]）：

1. **表决权差异安排**：有限责任公司章程对表决权的特别规定空间
   [CITE:__]；注意与「同股同权」原则的衔接、对中小股东的影响——
   立场视角在此分化：控股股东视角看稳定性，中小股东视角看压制
   风险；
2. **分红约定**：不按出资比例分红的章程安排或全体股东约定的效力
   空间 [模型知识—待核实，引用前经 statute-verify 核验]；
3. **股权转让限制**：章程对转让增设条件（同意权、优先购买权强化、
   转让禁止期）的合法性边界——限制至实质禁止转让的条款效力存疑，
   标 [需复核] 并建议检索最新裁判口径；
4. **其他自治条款**：知情权的章程扩展、会议通知的特别约定、董事长
   特别职权等，逐条按三圈分类。

触碰强制性规定底线的，法律风险轴 🔴 并注明「条款存在无效风险」
[CITE:__]；边界存疑的标 🟡 并写明存疑点。

### 第 5 步：章程与股东协议冲突核查

- 询问是否存在股东协议、合资合同、增资协议；存在的，调取关键条款
  （治理席位、表决安排、转让限制、回购）与章程逐条对照；
- 冲突处理口径：章程与股东协议冲突时的对内/对外效力问题属裁判
  规则演进领域 [模型知识—待核实]，提示并列冲突点，建议经
  `shareholder-agreement-review` 专项处理；
- 冲突点按 G9 双轴标注，法律风险轴不低于 🟡。

### 第 6 步：三色分桶与输出 memo

- **🟢 可推进**：必备事项齐备、无与新法冲突、自治条款均在合法边界内。
  🟢 只能基于经 statute-verify 核验的依据给出；未核验时最高 🟡
  （场景 B3）。
- **🟡 需修订**：存在 work-but-ships 项（冲突可修订、缺项可补）；
  逐项给修订方向与建议时限，并提示章程修订须履行的法定程序（股东会
  特别决议、变更登记）[CITE:__]。
- **🔴 不得推进**：命中 A8.1 blocks（如章程安排服务于规避出资义务）；
  或核心条款存在无效风险且整体结构受其影响。
- 按下方模板输出 memo。执行摘要只放机械性一行修改；需要起草新语言
  的只写「**建议转法务/律师起草**」。

### 第 7 步：后果门与收尾（对应 G5）

- 结论含 🔴：首页明示「**本章程版本不提交签署/登记**」，按 G5 生成
  「带给律师的一页 brief」，非律师用户到此停止。
- 结论 🟢/🟡 且将提交股东会或登记机关：非律师用户走 G5 动作闸门——
  显式确认知悉提交的法律后果并获得明确指令，生成律师 brief。
- 收尾：memo 与所审版本按 `matter-workspace` 版本规则保存；全部引用
  过 `citation-audit`；提示章程修订走决议程序时接续 `board-resolution`。

## 本技能不做什么

- 不代拟章程条款或修正案语言——需要起草的一律「建议转法务/律师起草」。
- 不凭默认值给 🟢：法条未经 statute-verify 核验时，结论天花板是 🟡。
- 不混用公司类型规则：有限公司与股份公司的章程规则分别适用。
- 不对自治条款一刀切：先分三圈再下结论，允许的空间不轻易标红。
- 不处理 🔴 事项的后续（不出规避方案，生成律师 brief 后停止）。
- 不做工商登记代办建议：登记程序细节以登记机关要求为准，标 [需复核]。
- 不直接手改画像：现场取得的立场与公司信息经 `customize` 写回。

## 收尾与下一步

1. memo 交付后按第 7 步后果门分流：🔴 停止并升级；🟡 修订后复审；
   🟢 走 G5 显式确认 + 律师 brief。
2. 章程修订须履行决议程序的 → 接续 `board-resolution`；出资期限
   调整、减资需求的 → 接续 `capital-contribution`；与股东协议冲突的 →
   接续 `shareholder-agreement-review`。
3. 全部引用过 `citation-audit`；修订后的章程版本与登记版本留档。
4. 审查中发现画像缺口（公司类型、本方角色、行业规则），提示经
   `customize` 补齐。
5. 新公司法配套规则（登记管理、过渡期安排）更新时，提示对存量章程
   复核——本插件结论的时效以 reviewer note 的核查日期为准。
