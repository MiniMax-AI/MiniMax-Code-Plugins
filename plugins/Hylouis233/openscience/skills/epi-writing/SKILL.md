# epi-writing：公共卫生写作规程

## 目的

把 outbreak-analysis / spatial-epi / seir-modeling 的分析产物变成两类
成稿：**暴发调查报告**（内部/上报纸质文书）与**观察性研究论文**
（中文期刊投稿）。本技能给出两种文体的结构模板、STROBE 自查规程与
GB/T 7714 参考文献格式要点，并在收尾强制执行引用核验。

铁律：

1. 每个数字都能回溯：报告中的病例数、率、RR/OR、峰值必须与分析
   产物（脚本输出/表格）一致；新出现的数字写明算式与来源。
2. 来源标注贯穿成稿：沿用分析阶段的来源标签直至定稿，交稿前按
   目标场景决定是否转为正式参考文献著录（内部报告保留标签）。
3. 发布前审查（guardrail 第 7 条）：交付前必须经过 reviewer 审查或
   核验类 skill 检查，error 清零方可交付。

## 前置检查

1. 分析产物齐备：曲线/表格/地图来自 `output/<skill>/<slug>/latest/`
   或已定稿的路径；引用中间稿时注明版本。
2. 成稿类型与读者明确：暴发调查报告（行政/技术读者）与期刊论文
   （学术读者）的结构与措辞不同，不混用模板。
3. 可披露性确认：疫情细节、地名、单位名是否可写，由用户按权限
   决定；对外发布属 guardrail 第 8 条危险操作。
4. 伦理信息在手：批件编号/豁免证明、知情同意说明（涉及人数据时）。

## 1 · 暴发调查报告模板

按现场流行病学调查报告惯例组织 [模型知识—待核实：具体格式要求以
接收单位（疾控机构/卫生行政部门）的现行规定为准]：

```markdown
# <事件名称>调查报告

## 一、背景
- 发现经过：首报时间、报告来源、启动调查的时间与组成 [用户提供]
- 事发地概况：人口、地理、相关卫生资源（只写与事件相关的）

## 二、方法
- 病例定义：疑似/临床/确诊分层标准（逐字）
- 病例搜索：途径与范围
- 调查方法：个案调查/问卷、实验室检测方法、统计分析方法
  （含使用的脚本/软件与版本）
- 数据伦理：去标识化与伦理审批情况

## 三、结果
- 流行强度：总病例数（分层）、罹患率（分子/分母口径）
- 三间分布：时间（流行曲线）、地点、人群
- 暴露分析：2×2 表、RR/OR 及其来源
- 实验室结果：阳性率、病原学分型

## 四、控制措施
- 已采取措施与启动时间；措施对应的目标（切断传播途径/保护易感者）
- 措施效果初步观察（如有）

## 五、讨论
- 主要发现一句话概括；假设及证据强度
- 局限：发现滞后、回忆偏倚、检测能力、分母不确定
- 建议：可操作的下一步（监测、补种、水源管理等）

## 附
- 病例定义原文、问卷、曲线图、表格、provenance 编号
```

写作纪律：结果节只放观察，讨论节才放解释；控制措施按"谁在何时
做了什么"写，不评价职权外事项。

## 2 · 观察性研究写作与 STROBE 自查

期刊论文按 IMRaD（引言/方法/结果/讨论）组织，并用 **STROBE 声明**
（加强观察性流行病学研究报告质量）的 22 条核对清单逐项自查
[模型知识—待核实：STROBE 2007 年发表、针对队列/病例对照/横断面
设计各有版本，共 22 个条目；条目原文以 STROBE 官网/原文为准]。

自查规程：

1. 按研究设计选对应版本的清单（cohort / case-control /
   cross-sectional）。
2. 22 条逐条在稿件中定位对应段落，制作"条目 → 稿件位置"对照表；
   缺项只有两种处理：补写，或在投稿信中说明不适用理由——不留
   "忘了写"的条目。
3. 高频漏项提醒（经验性，标 [模型知识—待核实]）：研究设计命名、
   研究现场与时间、变量定义、偏倚控制方法、样本量考虑、统计方法
   细节（混杂与缺失值处理）、各阶段人数流程、效应估计的精度
   （区间而非仅 P 值）、资金来源与利益冲突。
4. 对照表作为投稿附件保留；审查时 reviewer 可直接核对。

## 3 · 中文期刊格式与 GB/T 7714 参考文献

中文公卫期刊（如《中华流行病学杂志》《中国公共卫生》等）通常要求：

- 结构：中英文摘要（目的/方法/结果/结论四段式）、关键词 3–8 个、
  正文 IMRaD、利益冲突与伦理声明、参考文献 [模型知识—待核实：
  各刊细则以当年稿约为准，投稿前查目标刊最新稿约]。
- 参考文献按 **GB/T 7714—2015** 著录；国内期刊多用**顺序编码制**
  （正文引用处上标数字，文后按出现顺序排列）。
- 常见文献类型标识（专著 M、期刊文章 J、标准 S、电子资源 EB/OL
  等）与著录要素顺序（主要责任者. 题名: 其他题名信息[文献类型
  标识]. 出版地: 出版者, 出版年: 页码.）[模型知识—待核实：细则
  以标准原文为准]。
- 电子资源需标引用日期与获取路径；疫情通报、政府公告按电子资源
  或报告类著录，并保留发布机构全称。

著录纪律：

1. 文后每条文献必须在正文有引用点，反之亦然；
2. 著录信息来自检索记录或原文，不凭记忆补全卷期页码；
3. 分析阶段的来源标签（`[WHO-GHO]` 等）在定稿时逐条转为正式
   著录条目，转换过程保留对照底稿备查。

## 4 · 收尾：引用核验（强制）

参考文献整理完成后、交付之前，**必须**运行
`citation-verify` 对文献清单做机器核验：

1. 将参考文献整理为 .bib 或按 citation-verify 要求的格式输入；
2. 处理核验结论：标识符冲突与查不到的条目逐条人工核对原文，
   不直接采信任何一方的自动结论；
3. 核验报告连同 reviewer 的 ```review 围栏意见一并归档；
4. error 级 findings 清零后方可交付（guardrail 第 7 条）。

## 输出模板

交付前自检输出：

```markdown
## 成稿交付检查（<日期>）

- 文体：暴发调查报告 / 观察性研究论文；目标：<单位/期刊>
- 数字一致性：报告数字 vs 分析产物 <路径> 已逐项核对
- STROBE：22 条对照表见附件，缺项 <n> 条均已说明（论文适用）
- 参考文献：GB/T 7714—2015 顺序编码制；共 <n> 条，
  citation-verify 通过/残留问题 <清单>
- 伦理与披露：批件 <编号>[用户提供]；地名/单位名披露口径 [用户提供]
- 审查：reviewer 意见 <error 0 / warn n>，warn 处置：<接受/已改>
```

## 本技能不做什么

- **不代写实质学术判断**：讨论节的证据强度评价、外推边界由作者
  负责；本技能搭结构、查缺项，不替作者下结论。
- **不保证期刊接收口径**：各刊格式细则以当年稿约为准；本技能
  只给通用框架与自查方法。
- **不绕过审查**：未经 reviewer 或 citation-verify 检查的稿件不
  标记为"可交付"。
- **不处理英文期刊投稿细节**：英文写作辅助由 review-writing
  承担；本技能聚焦中文公卫文体。
- **不编造著录要素**：卷期页码、DOI 查不到就如实留空并标注，
  待 citation-verify 复核。

## 收尾与下一步

1. 汇总：成稿类型、字数、附件清单、引用核验状态。
2. 指向 `papers/` 中的成稿与 `reviews/` 中的审查记录。
3. 建议下一步：
   - 运行 `citation-verify`（若尚未做）；
   -  按 reviewer-protocol 全稿审查（发布前最后关口）；
   -  用户确认后执行对外提交/报送（危险操作，逐项说明再执行）。
